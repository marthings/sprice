# App Review Notes

This is a macOS menu bar app. After launching the app, click the Sprice icon in the macOS menu bar to open the main app interface.

Core functionality available without provider login:
- Current Swedish spot electricity price
- Daily price chart
- Price area selection for SE1, SE2, SE3 and SE4
- Estimated total electricity cost using user-selected settings

Optional provider integrations:
- Tibber integration requires the user's own Tibber API token.
- Vaggeryd Energi integration requires the user's own customer credentials.
- These integrations are optional and are used only to show the user's electricity consumption data.

Grid fees and total cost:
- Grid fees, fixed fees and total cost values are shown as estimated values.
- The app labels these values as estimates because actual fees can vary by contract, grid operator and billing period.

The app does not include AI analysis, in-app purchases, hidden features or dormant functionality.
